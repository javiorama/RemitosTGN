# Generador de Remitos - TG Norte

Webapp para generar remitos automáticamente desde órdenes de Smartier.

## Características

- ✅ Scrapea órdenes de Smartier
- ✅ Genera remitos en HTML printeable
- ✅ Descarga como PDF
- ✅ Numeración automática de remitos
- ✅ Interfaz profesional con Tailwind CSS

## Stack

- React 18 + TypeScript
- Tailwind CSS
- Vite
- Lucide Icons

## Desarrollo Local

```bash
npm install
npm run dev
```

Accede a http://localhost:5173

## Build para Producción

```bash
npm run build
```

## Deploy en Vercel

Este proyecto está configurado para deployar automáticamente en Vercel.

1. Conecta tu repo de GitHub a Vercel
2. Vercel detectará automáticamente que es un proyecto Vite
3. Deploy automático en cada push a main
